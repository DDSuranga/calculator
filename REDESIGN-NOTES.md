# OnlineCalMaster redesign maintenance

The authoritative website is the root index.html, styles.css and script.js. The 35 calculator directory index.html files are generated entry documents, not separate calculator implementations.

After editing the root application shell or calculator registry:

    node scripts/generate-calculator-pages.js
    node scripts/generate-seo-files.js
    node qa-regression.js
    node qa-step3-calculators.js
    node qa-service-worker.js

Preview with `node scripts/serve-preview.js` at http://127.0.0.1:5501. This server serves actual files and redirects directories; it does not hide broken routes with a universal fallback.

GitHub Pages serves each calculator at /slug/. Existing /slug links redirect to the directory route. Metadata, canonical URLs, sitemap entries and generated links use /slug/ consistently. Commit the regenerated pages with the source changes. No custom frontend build or framework is required.

The service worker uses network-first requests for first-party application resources, keeps a shared offline shell and retains unrelated cache namespaces. Increment its cache version when changing the offline asset set.

The Electron wrapper, packaged downloads and commercial source package were deliberately not regenerated by this website release. They remain separate local artifacts.
